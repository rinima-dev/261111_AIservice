# 05. 기능 구현 지침 - Supabase 피드백 연동 (Supabase Feedback Guidelines)

## 1. Supabase 데이터베이스 테이블 생성
Supabase SQL Editor에서 아래 명령어 실행하여 테이블 및 보안 정책(RLS)을 작성합니다.

```sql
-- 1. 피드백 테이블 생성
CREATE TABLE feedbacks (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL,
  nickname TEXT NOT NULL,
  rating INT CHECK (rating >= 1 AND rating <= 5) NOT NULL,
  content TEXT NOT NULL
);

-- 2. RLS (Row Level Security) 활성화
ALTER TABLE feedbacks ENABLE ROW LEVEL SECURITY;

-- 3. 비로그인 사용자도 피드백을 등록할 수 있도록 허용
CREATE POLICY "누구나 피드백 작성 가능" ON feedbacks
  FOR INSERT WITH CHECK (true);

-- 4. 누구나 피드백 목록을 조회할 수 있도록 허용
CREATE POLICY "누구나 피드백 조회 가능" ON feedbacks
  FOR SELECT USING (true);
```

## 2. 프론트엔드 연동 로직 (`feedback.js`)
- CDN 방식으로 Supabase 클라이언트 불러오기:
  `<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>`

- **피드백 등록 함수**:
```javascript
async function submitFeedback(nickname, rating, content) {
  const { data, error } = await supabaseClient
    .from('feedbacks')
    .insert([{ nickname, rating, content }]);
  if (error) throw error;
  await fetchAndRenderFeedbacks(); // 작성 후 목록 즉시 갱신
}
```

- **피드백 최신순 조회 및 표시 함수**:
```javascript
async function fetchAndRenderFeedbacks() {
  const { data, error } = await supabaseClient
    .from('feedbacks')
    .select('*')
    .order('created_at', { ascending: false }); // 최신순 정렬
  if (error) throw error;
  renderFeedbackList(data);
}
```
