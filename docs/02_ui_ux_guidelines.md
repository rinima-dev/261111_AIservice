# 02. UI 구현 지침 (UI/UX Guidelines)

## 1. 디자인 시스템 & 컬러 팔레트
- **메인 컬러 (Primary)**: `#4F46E5` (인디고 블루 - 신뢰감 및 학습 집중)
- **보조 컬러 (Secondary)**: `#10B981` (에메랄드 그린 - 완료 및 성공)
- **배경 컬러 (Background)**: `#F9FAFB` (연한 회색 - 눈의 피로도 감소)
- **텍스트 컬러 (Dark Accent)**: `#1F2937` (슬레이트 블랙 - 가독성 제공)
- **경고/에러 컬러 (Error)**: `#EF4444` (코랄 레드 - 에러 및 경고)
- **폰트**: 기본 시스템 폰트 스택 (`system-ui, -apple-system, sans-serif`)

---

## 2. 화면 영역별 구성 요소

1. **상단 헤더 (Header)**:
   - 서비스 타이틀 ("AI 스마트 학습 플래너") 및 서브 타이틀 위치

2. **영역 1: 학습 목표 설정 폼 (Input Section)**:
   - 학습 목표 입력란 (text input)
   - 학습 기간 입력란 (number input, 일 단위)
   - 하루 학습 가능 시간 (number input, 시간 단위)
   - 현재 학습 상태 (select 또는 text input)
   - 생성하기 버튼 (`#4F46E5` 배경색 적용)

3. **영역 2: 대시보드 & 로드맵/스케줄 (Dashboard Section)**:
   - **로드맵 뷰**: 단계별(Milestone) 카드 형태 표시
   - **일일 스케줄**: 체크박스 목록 (체크 시 완료 처리)
   - **성과 분석 요약**: 주간/월간 달성률(%) 프로그레스 바 형태 표시

4. **영역 3: 과목 질의응답 챗봇 (Q&A Section)**:
   - 질문 입력창 및 전송 버튼
   - 답변 출력 상자 (로딩 중 스피너 표시)

5. **영역 4: 공통 오류 메세지 알림창 (Toast Notification)**:
   - 우측 상단 고정, 에러 발생 시 부드럽게 나타났다가 desaparecer(사라짐) 효과 적용

6. **영역 5: 하단 피드백 영역 (Bottom Feedback Section)**:
   - 닉네임, 별점 선택, 내용 입력 폼
   - 최신순 피드백 목록 카드가 열거되는 리스트 영역

---

## 3. UI 제약 조건 및 검증 기준
- 외부 CSS 프레임워크(Tailwind, Bootstrap 등) 사용 금지 (Pure CSS 작성).
- 데스크톱(1280px) 및 모바일(375px) 화면 크기에서 요소가 겹치거나 깨지지 않아야 함.
- 모든 버튼 및 입력 필드는 마우스 호버(Hover) 및 포커스(Focus) 시 시각적 피드백 제공.
